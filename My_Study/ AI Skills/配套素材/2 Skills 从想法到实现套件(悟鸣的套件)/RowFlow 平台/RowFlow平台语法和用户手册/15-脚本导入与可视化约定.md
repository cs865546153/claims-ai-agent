# 脚本导入与可视化约定

适用版本：RowFlow 演示规范 1.0；浏览器导入协议 1.0。本文补充 HTML 课堂界面的导入与解释执行方式，不增加 Groovy 关键字，也不改变 01～06 的平台 DSL。

## 1. 导入什么

在工作台点击“导入脚本”，选择或拖入 UTF-8 `.groovy` 文件，也可以粘贴完整脚本。单个文件不超过 256 KiB，支持 UTF-8 BOM；不是批量导入。文件内容保存在当前页面会话，导入成功后可导出完整内容。粘贴 AI 回复时可自动提取唯一的 Groovy 代码块；多个 Groovy 块会要求先选择，避免误合并。浏览器文本编辑会把换行归一为 LF，UTF-8 BOM 会移除。

脚本必须包含恰好一个 pipeline 和 emit。解析失败时保留原工作台及脚本，不用错误文件覆盖当前场景。解析成功但运行数据有错误时，可导入查看图、失败节点和日志，再修改或补充样例后重试。

平台从脚本的真实 from、操作符、变量引用和 emit 构建有向图，不依赖文件名或预设场景 ID。没有注释也能识别节点；不能用注释掩盖脚本中的未知 API、重复消费者或计算错误。

## 2. 可选的节点讲解注释

```groovy
// @step paid_orders 筛选已支付订单
def paid = orders.filter { r -> r['status'] == 'PAID' }
```

格式为 `// @step <节点ID> <中文标题>`，放在对应 def 或 emit 语句之前。ID 使用 `[a-z][a-z0-9_]{0,63}` 且文件内唯一，标题最长 80 个字符。

- 注释不参与业务计算，只给图中的节点命名。
- 一个语句如果串联多个操作符，解析器仍展示全部操作符；注释命名该语句最后产生的节点。
- 为方便逐步讲解，推荐一个 def 对应一个操作符；复用变量应遵守单一下游消费者规则。
- from、普通流、groupBy 的分组描述及 emit 都可命名。普通参数变量或 source 注册语句不使用 @step。
- 没有 @step 的节点自动命名；重复 ID、连续注释或缺少对应语句会提示错误。

## 3. 可选的本地样例注释块

memory 数据源自带 rows，不需要额外样例。HTTP/RPC 数据源需要本地 JSON 响应，放在脚本开头的普通块注释中：

```groovy
/* @rowflow-demo
{
  "version": "1.0",
  "title": "订单筛选",
  "description": "使用本地 HTTP 响应演示筛选。",
  "parameters": {"tenantId": "T001"},
  "mocks": {
    "orders": {
      "response": {
        "data": {"items": [{"orderId": "O1", "status": "PAID"}]}
      }
    }
  }
}
*/
```

此块是片段，需与完整 pipeline 一起使用。内容必须为标准 JSON，使用双引号、不带尾逗号。一个文件最多一个块，`version` 必须为 `"1.0"`。顶层只支持 version、title、description、parameters、mocks。

| 字段 | 用途 |
| --- | --- |
| title / description | 页面标题和讲解说明，可省略 |
| parameters | 演示默认运行参数；工作台“运行参数”的同名值覆盖它 |
| mocks | 按脚本 source 名称提供本地响应；名称必须实际声明 |
| mocks.源名.response | 完整响应信封，仍通过脚本 rowsPath/recordPath 定位并校验类型 |

注释不接受 expectedRows、结果快照、JavaScript 函数或另一套可执行图。图、节点代码、行数和输出都从实际脚本及样例计算。

浏览器在演示已知订单、用户接口时可以使用内嵌契约；新接口需提供自己的 mocks。真实凭据、密钥、生产数据不能放进注释。这里的 JSON 是本地演示输入，不会向配置的 URL 发请求，也不能证明接入权限已经验证。

## 4. lookup 的样例和失败

可以给查询型源提供固定 response，也可按动态请求键选择对象：

```json
{
  "lookup": {
    "key": "userId",
    "records": {
      "U001": {"userId": "U001", "city": "杭州"}
    }
  }
}
```

这是单个 `mocks.源名` 的值。读取动态与静态合并后的 userId，找到对象后按脚本 recordPath 包装；缺少键返回显式 null。随后由 lookup 的 mode 决定保留或丢弃输入行。

失败样例可改用 `{"error":{"code":"RF-SRC-001","message":"样例超时"}}`；code 仅支持 RF-SRC-001/002。`retryable:true` 表示可重试的模拟调用失败，是否重试还取决于源 retries 和幂等声明。模拟不会真的等待网络超时，所有尝试仍计入请求数；真实授权与服务目录需由宿主检查。

## 5. 节点展示与单步运行

导入后点击节点，可查看：

1. **环节脚本**：该节点对应的实际源码及行号，不是根据标题拼出的代码。
2. **输入数据**：进入该环节的全部样例行；join 分别展示左输入和右输入。
3. **输出数据**：该环节实际计算的结果及行数；空结果明确显示空态。
4. **执行状态**：等待、成功或失败；错误定位到实际失败节点。

groupBy 产生 GroupedRows，不是普通 RowStream。其节点展示“分组描述”，以分组键和 inputRows 解释分组情况，不把这份讲解摘要当成真实输出 Row。

“运行演示”按依赖顺序演示所有环节；join 先读取右流。“单步演示”每次推进一个实际执行节点，播放本次解释得到的快照，方便逐环节讲解；它不是 JVM 断点调试器。最终结果、执行日志、调用数和运行记录同步更新。

## 6. 解释器支持范围

浏览器实现了受限 DSL 解释器，逐 Token 解析，不使用 JavaScript eval、Function 或外部 Groovy 服务。它根据输入脚本计算，区别于旧界面的固定模板对照。

| 类别 | 本地解释器支持 |
| --- | --- |
| 结构 | 一个 pipeline、source、from、emit；局部 def；显式参数闭包；return；闭包内 if/else |
| 数据 | 单/双引号普通字符串、十进制数和 G/L 后缀、Boolean/null、Map/List、字段索引 |
| 表达式 | 比较、算术、逻辑、三元与 Elvis、param、decimal、row、安全导航 |
| 单流 | filter、map、flatMap、withFields、select、distinct、sorted、skip、limit |
| 多源 | join、union、lookup；内存数据与提供本地响应的 HTTP/RPC |
| 聚合 | groupBy、全局/分组 aggregate；count、countNonNull、sum、avg、min、max |
| 值方法 | 03 所列常用字符串和容器读取方法、局部 List.collect |

这不是完整 Groovy 编译器。GString 插值、任意类、import、注解、反射、直接网络、文件和线程均不能在浏览器执行。遇到解释器没有实现的合法 Groovy 写法，会显示 RF-DEMO-SYNTAX，不能据此断定真实平台也不支持。

为保存逐节点数据，本地解释器按有界数据物化各环节；不复现真实宿主的惰性取消、网络等待、磁盘、授权和任务队列调度。特别是 limit 不能用来演示上游“不再读取”的行为；源仍会先被解释器完整读取。十进制运算使用精确有理数，avg 按 2 位 HALF_UP；JSON 展示限制在浏览器安全数值范围内。

演示资源上限：100 个节点、50000 个 Token、500000 个表达式计算步骤；另检查 pipeline 的行数、输出数、lookup 请求数和总执行时限。示例源码过大、超深表达式等会主动停止，避免页面失去响应。

## 7. 错误分类与修复

| 类别 | 说明与处理 |
| --- | --- |
| RF-DSL / RF-CONFIG / RF-TYPE / RF-SRC 等 | 本地已实现的对应规范校验，参见 06 |
| RF-DEMO-SYNTAX | 浏览器解析子集不支持或语句不完整；对照本章简化写法 |
| RF-DEMO-META | 注释 JSON、节点 ID 或样例字段不合法 |
| RF-DEMO-MOCK | 远程源缺少本地样例；补 mocks，不能把缺样例当成空数据 |
| RF-DEMO-LIMIT | 超出浏览器演示资源或安全数值范围 |

导入错误在对话框里展示，原场景保留；数据执行错误在图与日志中展示，没有部分业务结果。修改脚本或运行参数后重新解析，旧图和快照不能继续冒充新代码的结果。
