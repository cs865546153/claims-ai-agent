# 大模型推理全流程解析

> **核心结论**：稠密模型推理 = **全参数跑一遍**，没有「只用一部分参数」的机制。

---

## 1. 完整推理流程总览（以 LLaMA-7B 为例，约 6.7B 参数）

```
用户输入 → 分词 → Embedding查表 → 32层Transformer前向传播 → 输出头 → 采样 → 下一个Token
                                    ↑                    ↑
                                 稀疏查表            稠密矩阵乘法（全参数）
```

---

## 2. 逐步详解

### 步骤 1：分词

| 输入文本 | Token ID | 对应词 |
|----------|----------|--------|
| 请 | 4872 | "请" |
| 你 | 3121 | "你" |
| 告诉我 | 29871 | "告诉我" |
| 猫 | 13012 | "猫" |
| 有 | 32001 | "有" |
| 几 | 29879 | "几" |
| 个 | 9123 | "个" |
| 耳朵 | 29901 | "耳朵" |

- **8 个 Token**，每个是一个整数（词表索引，范围 0~127,999）

---

### 步骤 2：Embedding 查表（唯一「稀疏」操作）

```text
Input IDs (8,) → Embedding Matrix [128000, 4096] → Hidden States (8, 4096)
```

- **只读取 8 行**，其余 127,992 行完全不碰
- 得到 **8 个 4096 维向量**（每个 Token 一个）
- **Embedding 矩阵本身占模型参数约 7%**，查表时仅稀疏读取

> **类比：词典查诼**
> - 词典共 128,000 词条
> - 你只查这 8 个词的释义，剩下十几万词条翻都不翻
> - 查到的释义（4096 维向量）交给后面 Transformer 去理解语义

> **关键点**：Embedding 仅生成**单词独立基础语义向量**，不理解上下文、不做推理、不检索事实知识。上下文语义、关联关系、事实知识，由后续 Transformer 多层前向计算完成。

---

### 步骤 3：32 层 Transformer 全密集前向传播（核心算力）

#### 3.1 每一层做两件事（全参数参与）

```
Layer 1..32 循环：
    Attention（跨 Token 信息混合） → FFN（单 Token 内部知识提取） → 残差连接
```

**参数分布（单层 ≈ 2 亿，32 层累计 ≈ 6.7B）：**

| 组件 | 矩阵数量 | 形状 | 参数量占比 |
|------|----------|------|------------|
| Attention (Q/K/V/O) | 4 | [4096, 4096] | ~50% |
| FFN (Gate/Up/Down) | 3 | [4096, 11008] / [11008, 4096] | ~50% |

---

#### 3.2 Attention：跨 Token 信息混合

```python
# 形状：Hidden (8, 4096)
Q = Hidden @ W_Q      # (8, 4096) @ (4096, 4096) → (8, 4096)
K = Hidden @ W_K
V = Hidden @ W_V
Attn = softmax(Q @ K^T / √d) @ V   # 8 个 Token 互相看对方
Hidden = Hidden + Attn @ W_O        # 残差连接
```

> **类比**：读句子时，每个词都在扫一眼整句话里别的词，判断谁和谁有关系。
> - "耳朵" → 重点关注「猫」，知道是猫的耳朵
> - "有几个" → 关联后面要回答数量
> - "请你告诉我" → 识别这是指令

> **本质**：上下文信息混合。没有 Attention，每个词的向量是孤立的。

---

#### 3.3 FFN：单 Token 内部知识提取

```python
Gate = Hidden @ W_Gate    # (8, 4096) @ (4096, 11008) → (8, 11008)
Up   = Hidden @ W_Up      # (8, 4096) @ (4096, 11008)
Down = SwiGLU(Gate, Up) @ W_Down   # (8, 11008) @ (11008, 4096)
Hidden = Hidden + Down    # 残差连接
```

> **类比**：每张卡片，在看完别的卡片（Attention）之后，**独自翻自己脑子里的知识库，补充事实细节**。
> - "猫" 向量在 FFN 中唤醒：猫是动物、有头、耳朵数量 2、有尾巴……
> - 知识分布式存在权重矩阵里，矩阵乘加运算 = "检索 + 组合知识"

> **重点区分**：
> | 组件 | 职责 | 类比 |
> |------|------|------|
> | **Attention** | 跨 Token 通信（词 ↔ 词） | 互相交流、对齐指代 |
> | **FFN** | 单 Token 内部知识提取 | 单独脑补事实细节 |

---

#### 3.4 32 层 = 反复精读、深度思考

| 层级 | 职责 | 类比 |
|------|------|------|
| **浅层 (1~4)** | 语法、词性、句子结构 | 扫一眼句子骨架 |
| **中层 (5~20)** | 语义理解、意图识别 | 读懂「在问猫耳朵数量」 |
| **深层 (21~32)** | 激活事实知识、锁定答案 | 确定答案是「2」 |

> 每一层都在上一层加工完的向量基础上，做一轮更深度的提炼。

---

#### 3.5 KV Cache 补充

> 自回归生成后续 Token 时会启用 **KV Cache**，缓存 K/V 的中间激活向量，**但权重矩阵依然全部参与运算，不会减少参数参与**。

---

### 3.6 规模扩展对比：7B vs 70B（稠密模型）

| 维度 | LLaMA-7B | LLaMA-70B | 倍数 | 影响 |
|------|----------|-----------|------|------|
| **隐藏维度 `d_model`** | 4,096 | **8,192** | **2×** | 向量宽度，信息容量 |
| **FFN 隐藏层 `d_ff`** | 11,008 | **28,672** | **2.6×** | 知识抽屉数量 |
| **层数 `n_layers`** | 32 | **80** | **2.5×** | 思考深度 |
| **注意力头数** | 32 | **64** | 2× | 并行关注能力 |
| **总参数量** | 6.7B | **70B** | **~10×** | 模型容量 |

#### 对步骤的具体影响

| 步骤 | 7B | 70B | 关键差异 |
|------|-----|-----|----------|
| **步骤 2：Embedding** | `[128k, 4096]` → 4096 维向量 | `[128k, 8192]` → **8192 维向量** | 同词表，**向量维度 2×**，语义分辨率更高；查表仍稀疏（只读 8 行） |
| **步骤 3：Attention** | `Q/K/V/O: [4096, 4096]` | `Q/K/V/O: [8192, 8192]` | 矩阵乘法 **4× 计算量**（O(d²)） |
| **步骤 3：FFN** | `Gate/Up: [4096, 11008]`<br>`Down: [11008, 4096]` | `Gate/Up: [8192, 28672]`<br>`Down: [28672, 8192]` | **~5.2× 计算量**，知识空间更大 |
| **步骤 3：层数** | 32 层 | **80 层** | **2.5× 深度**，反复精读轮数更多 |
| **总前向算力** | 基准 | **~10-15×** | 参数量 10× + 层数 2.5× |

> **结论**：稠密模型下，**1000 亿参数全都参与计算**，只是矩阵更大、层数更多。Embedding 向量维度更高，Attention/FFN 矩阵乘法计算量平方级增长。

### 3.7 核心公式：参数量估算（必背）

> **Transformer 稠密模型参数量 ≈ 12 × n_layers × d_model²**
> （主导项是 FFN，占 ~75%）

#### 推导速记

```
单层参数拆解：

Attention (Q/K/V/O):
  4 个投影矩阵:  4 × d_model × d_model = 4 d²

FFN (Gate + Up + Down, SwiGLU):
  d_ff 通常 ≈ 8/3 d_model (LLaMA: 11008/4096 ≈ 2.69)
  3 × d_model × d_ff ≈ 3 × d_model × (8/3 d_model) = 8 d²

LayerNorm / Bias 等: ~0.5 d² (可忽略)

单层总计 ≈ 4 d² + 8 d² = 12 d²
全模型 ≈ 12 × n_layers × d_model²
```

#### 实测验证（LLaMA 系列）

| 模型 | n_layers | d_model | 公式估算 | 官方值 | 误差 |
|------|----------|---------|----------|--------|------|
| **7B** | 32 | 4096 | 12 × 32 × 4096² ≈ **6.44B** | 6.7B | ~4% |
| **13B** | 40 | 5120 | 12 × 40 × 5120² ≈ **12.6B** | 13B | ~3% |
| **70B** | 80 | 8192 | 12 × 80 × 8192² ≈ **64.5B** | 70B | ~8% |
| **405B** | 126 | 16384 | 12 × 126 × 16384² ≈ **408B** | 405B | ~1% |

> 误差来源：Embedding + Output Head + LayerNorm + d_ff 不完全等于 8/3 d_model

#### 为什么要懂这个公式？

| 场景 | 作用 |
|------|------|
| **秒算规模** | 给配置（层数、维度）30 秒心算参数量 |
| **解释缩放** | 为什么 `d_model` 翻倍 → 参数量 4×？（平方项主导） |
| **架构设计** | 目标 7B/70B/400B，反推需要多少层、多大维度 |
| **组件权衡** | FFN 占 75% → MoE 只切 FFN；Attention 占 25% → GQA/MQA 只切 K/V 投影 |

---

### 步骤 4：输出头

```text
Hidden (最后一层，最后一个 Token 位置) → [4096]
    → Output Head @ W_Out [4096, 128000] → Logits (128000,)
```

- Logits = 每个词的未归一化得分 $logits = f_\theta(\boldsymbol{X})$

---

### 步骤 5：采样 → 循环生成

```text
Softmax(Logits) → 概率分布 → Top-k / Temperature 采样 → 下一个 Token ID
```

**生成示例：**
```
29901 ("两") → 3121 ("个") → 29934 ("耳") → 29901 ("朵") → EOS
```

**循环**：把新 Token 追加回输入序列，再次送入 $f_\theta$，反复执行步骤 3~5，直到 EOS。

---

## 3. 为什么简单问题也要跑全参数？

| 理由 | 说明 |
|------|------|
| **1. 知识分布式存储** | 「猫有两只耳朵」不是存放在某几个神经元，而是分布在全网络数亿参数共同形成的权重模式里 |
| **2. 共享能力基座** | 即使问题简单，模型仍要解析句法、语义、意图；语言理解、指代、推理共用同一套参数 |
| **3. 架构限制** | 稠密 Transformer 是静态计算图，输入形状确定后计算路径固定，没有原生动态路由分支 |

---

## 4. 类比总结（仅类比，不等同于人脑）

| 概念 | 对应 |
|------|------|
| **参数** | 突触连接强度（固定不变） |
| **激活值** | 神经元放电模式（随输入动态变化） |
| **问「1+1=?」** | 大脑皮层大量神经元协同激活，不是单独启用一小块算术区 |
| **问「猫几只耳朵」** | 语言区、语义记忆、工作记忆协同工作 |

---

## 5. 核心公式速查

| 环节 | 公式 | 说明 |
|------|------|------|
| **Attention** | $\text{Attn} = \text{softmax}\left(\frac{QK^T}{\sqrt{d}}\right)V$ | 跨 Token 信息混合 |
| **FFN (SwiGLU)** | $\text{Down} = (\text{Gate} \otimes \text{Up}) W_\text{Down}$ | 单 Token 知识提取 |
| **残差连接** | $x_{l+1} = x_l + \text{Sublayer}(x_l)$ | 梯度流动、信息保留 |
| **输出分布** | $P(x_{t+1}|x_{1:t}) = \text{softmax}(h_t W_\text{out}^T)$ | 下一个 Token 概率 |

---

> **一句话**：简单问题、复杂问题，同一个模型、同一套参数、同一个计算图、全跑一遍。只是简单问题最后几层激活值「想得更确定」，Logits 峰值更尖锐而已。
