# 知识库 RAG 链路

## 多路召回

知识库 RAG 同时运行三路召回：

1. 稠密向量召回：使用 BGE-M3 将 query 与 chunk 编码为向量，通过 Milvus 做语义相似度检索。
2. BM25 关键词召回：对正文、标题和章节做词法统计，适合产品名、编号、专有名词和精确词项。
3. 元数据召回：匹配标题、章节、主题和来源路径，补足“用户直接问某篇文档”的场景。

三路结果先按 doc_id 去重，再用加权 RRF 融合。RRF 不直接相加不同量纲的分数，而是按排名计算 `weight / (k + rank)`。

## Rerank

RRF 只负责融合，不负责精排。候选片段随后送入 BGE-Reranker（Cross-Encoder），把 query 与文档拼接后成对打分，再取 Top-K。BGE-Reranker 服务不可用时，系统降级为词项重排，保证检索链路不中断。

## 引用校验

最终回答由 LLM 生成，但 citation_ids 必须属于本轮检索结果。没有有效引用时转人工核实，避免模型编造依据。
