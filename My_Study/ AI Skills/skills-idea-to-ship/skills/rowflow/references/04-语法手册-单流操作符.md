# 语法手册：单流操作符

适用版本：RowFlow 演示规范 1.0。本文中的代码以链式片段为主，放在 `from(...)` 与 `emit(...)` 之间使用。完整脚本见 [示例集](11-完整脚本示例.md)。

## 1. 接口速查

| 操作符 | 闭包或参数 | 返回值 | 行数变化 |
| --- | --- | --- | --- |
| `filter { r -> Boolean }` | 判断条件 | RowStream | 0 或 1 行/输入行 |
| `map { r -> Map或Row }` | 新记录 | RowStream | 1 行/输入行 |
| `flatMap { r -> List<Map或Row> }` | 子记录列表 | RowStream | 0 到多行/输入行 |
| `select('a', 'b')` | 一个或多个字段名 | RowStream | 不变 |
| `withFields { r -> Map }` | 覆盖合并的字段 | RowStream | 不变 |
| `distinct { r -> key }` | 去重键 | RowStream | 减少或不变 |
| `sorted { r -> key }` | 升序键 | RowStream | 不变 |
| `sorted([direction: 'desc']) { r -> key }` | 排序选项与键 | RowStream | 不变 |
| `skip(n)` | 非负整数 | RowStream | 跳过前 n 行 |
| `limit(n)` | 非负整数 | RowStream | 最多保留 n 行 |

除 `sorted` 外，这些操作符都保持输入中保留行的相对顺序。`flatMap` 按输入行顺序，再按该行返回列表的顺序展开。

## 2. filter：保留满足条件的行

```groovy
.filter { r -> r['status'] == 'PAID' && r['amount'] != null }
```

返回 `true` 保留，`false` 丢弃。返回 `null`、数字或字符串报 `RF-TYPE-001`。需要剔除无效记录时使用 `filter`，不要在 `map` 中返回 `null`。

## 3. map：生成完整的新行

```groovy
.map { r ->
    [orderId: r['orderId'], amount: decimal(r['amount'])]
}
```

输出只包含新 Map/Row 中的字段。原来的 `userId`、`status` 等字段不会隐式保留。返回 `null`、字符串或 List 都报类型错误。

## 4. withFields：保留原行并补充字段

```groovy
.withFields { r ->
    [amount: decimal(r['amount']), channel: 'WEB']
}
```

返回 Map 必须非空对象引用，允许内容为空 `[:]`。同名字段覆盖，未出现字段保留，嵌套 Map 整体替换。与 Row 自身的 `withFields(Map)` 区别见 [Row 手册](03-语法手册-Row与表达式.md)。

## 5. flatMap：一行展开为多行

输入记录：

```groovy
[orderId: 'O1001', items: [[sku: 'A', qty: 2], [sku: 'B', qty: 1]]]
```

展开片段：

```groovy
.flatMap { r ->
    def items = r['items'] == null ? [] : r['items']
    items.collect { item ->
        [orderId: r['orderId'], sku: item['sku'], qty: item['qty']]
    }
}
```

输出：

```json
[
  {"orderId": "O1001", "sku": "A", "qty": 2},
  {"orderId": "O1001", "sku": "B", "qty": 1}
]
```

返回 `[]` 表示该行不产生结果。返回 `null`、单个 Map、非列表集合，或列表里包含非 Map/Row 元素，均报类型错误。框架不会自动把父记录字段带入子记录，需要显式写入 `orderId`。

## 6. select：字段投影

```groovy
.select('orderId', 'amount')
```

按参数顺序构造新 Row，只保留指定顶层字段。不存在的字段输出为 `null`。字段名必须为非空 String，至少指定一个且不能重复。不支持 `'*'`、别名表达式或路径展开；别名用 `map`。

## 7. distinct：按键保留第一条

```groovy
.distinct { r -> r['orderId'] }
```

保留每个键首次出现的行，后续相同键被丢弃。去重不是按完整行比较；必须提供键闭包。联合键写成 `[r['tenantId'], r['orderId']]`。空键和类型比较规则见 [键语义](03-语法手册-Row与表达式.md)。

`distinct` 维护已见键集合，状态随不同键数量增长。1.0 不提供按时间自动过期或“保留最新一条”的选项。需要保留最新记录，可先按一致格式的时间降序排序，再去重。

## 8. sorted：稳定排序

```groovy
.sorted([direction: 'desc']) { r -> r['amount'] }
```

`direction` 只接受 `'asc'`、`'desc'`，默认 `'asc'`。键支持 Number、String、Boolean 或由它们组成的 List。Number 按数值排序；String 按字典序；Boolean 按 `false < true`。同一比较位置混用 String 与 Number 等不兼容类型，报类型错误。

List 按位置逐项比较，适合多字段排序；所有分量统一使用同一个方向。相等前缀时较短列表在升序中靠前。`null` 在任一方向都排最后；List 分量出现 `null` 时，该分量也按空值最后比较。相同键保持输入顺序。

框架先读取全部上游结果再排序。`sorted(...).limit(10)` 仍需先读全量数据，1.0 没有 Top-K 优化或磁盘溢写。

## 9. skip 与 limit：跳过和截取

```groovy
.sorted { r -> r['orderId'] }
.skip(10)
.limit(10)
```

这表示按订单号排序后返回第 11 到第 20 条。`skip(0)` 不跳过，`limit(0)` 返回空结果，超出已有数据时自然返回较少记录。负数和非整数为配置错误。

二者是本次读取结果上的截取，不是对远程接口的分页。`limit` 可停止继续向上游取行，但不会撤销已经发生的网络调用，或消除排序、聚合、关联右侧预加载等已完成的工作。

## 10. 推荐组合顺序

```groovy
def result = from('orders')
    .filter { r -> r['status'] == 'PAID' && r['amount'] != null }
    .withFields { r -> [amount: decimal(r['amount'])] }
    .filter { r -> r['amount'] >= 100.00G }
    .distinct { r -> r['orderId'] }
    .sorted([direction: 'desc']) { r -> r['amount'] }
    .limit(20)
    .select('orderId', 'amount')
```

顺序必须服从业务含义。例如先 `limit(20)` 再排序只会排列最先读到的 20 条；提前 `select` 丢掉 `userId` 会影响后续关联。平台不自动重排这些操作符。
