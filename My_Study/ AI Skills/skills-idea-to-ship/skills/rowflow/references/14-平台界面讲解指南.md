# RowFlow 平台用户手册与讲解指南

入口：[rowflow-demo.html](rowflow-demo.html)。用现代浏览器直接打开即可，离线可用，无需前端构建或网络服务。知识库内嵌框架、用户手册、导入协议及新场景资料。

界面支持完整脚本导入与导出。原有三个内置场景使用固定样例模拟；导入脚本由浏览器受限 DSL 解释器按实际代码计算，不要求与内置模板相同。它不是完整 Groovy 宿主，不访问真实 HTTP/RPC，不调用大模型。支持范围见 [15 导入约定](15-脚本导入与可视化约定.md)。

## 1. 推荐的新场景演示路线

1. 把语法手册 01～06、本用户手册、15 导入约定和 [16 库存补货场景](16-新场景-库存补货演示与AI提示词.md) 提供给 AI，用 16 中的提示词生成完整 .groovy。
2. 在工作台点击“导入脚本”，选择/拖入文件，或粘贴完整内容；核对文件名，点击“解析并导入”。
3. 查看解析出的真实依赖图，点库存、筛选、关联、补货预算、分组和汇总等节点。
4. 编辑器选“环节代码”时展示对应源码及原文件行号；右侧 Row 观察器看首条输出，下方“环节输入 / 输出”看完整样例记录。
5. 点击“运行演示”，依次观察各环节，再点击“单步演示”逐节点讲解。
6. 在“运行参数”中将 minBudget 改为 "2000"，重新解析，核对只保留上海仓。
7. 导出完整 .groovy 文件，或继续编辑再重新解析，展示代码变化如何改变图与结果。

参考脚本：[examples/inventory_replenishment.groovy](examples/inventory_replenishment.groovy)。可先导入它走通课堂流程，再导入 AI 新生成的文件。解释器不按文件名或脚本字节匹配结果。

## 2. 文件、拖放与粘贴导入

点击“导入脚本”打开对话框。支持单个 UTF-8 .groovy 文件，最大 256 KiB，兼容 UTF-8 BOM。文件选择和拖放只读取文本；粘贴时给出以 .groovy 结尾、不包含目录路径的文件名。支持从 AI 回复中提取唯一的 Groovy 代码块，多个块需先选定一份。

“填入库存补货示例”只填入参考文本，仍需点击“解析并导入”。当前执行未结束时不切换或导入新脚本。

- 空内容、扩展名错误、编码不合法、超限或语法不完整，都会显示明确反馈。
- 解析失败时保留当前工作台，不用错误文件覆盖原脚本。
- 解析成功但样例执行失败，仍可导入检查图、失败节点和代码；最终业务输出为空，日志说明错误。
- 新的远程源需要在普通注释中提供 mocks；缺少样例不是“空数据”。协议详见 [15](15-脚本导入与可视化约定.md)。

导入成功后，业务场景选择器会增加“已导入 · 文件名”。可切回内置场景，再切回导入场景；当前页面保留一份导入脚本，后续成功导入会替换它。刷新后会话清空。

## 3. 数据流与节点检查

数据图来自 from、操作符和 emit 的真实依赖。多个源连接到 join 时，能看到两条输入边；图较长时在图内横向滚动。@step 注释可为节点命名，没有注释会自动命名。

点击节点后：

| 展示位置 | 内容 |
| --- | --- |
| 环节代码 | 该操作符的实际源码片段及原文件行号；不是可独立运行的完整脚本 |
| Row 观察器 | 首条输出；无输出显示空态；错误显示错误码 |
| 环节输入 / 输出 | 左/单输入、join 右输入、输出记录及行数，可切换查看 |
| 节点状态 | 未执行、成功、失败或因上游失败而阻断 |

快照表最多展示前 100 行，并明确总行数；执行统计和最终 JSON 使用完整数据。groupBy 的输出视图标为 GroupedRows 分组描述，其 inputRows 是组内数量，不应误认为普通输出 Row。aggregate 的输入明细用于解释如何计算指标。

## 4. 运行演示与单步演示

导入时会先进行本地解释预览，便于立刻检查图和结果。点击“运行演示”重新计算当前代码和参数，并按真实依赖顺序播放各节点；join 先读取右流。运行期间禁用会改变脚本、参数或场景的控件，结束后恢复。

“单步演示”一次前进一个已执行节点，自动定位图和对应源码，切换输入/输出表，显示当前进度。到最后一步后再次点击，从第一步重新开始。某个节点失败后不执行其下游。

最终结果、JSON、日志和运行记录显示实际本地解释结果。解释器按有界样例物化各步，不能用来证明真实网络授权、Groovy 编译隔离、惰性取消或队列调度已实现。

## 5. 编辑、检查、参数与导出

- **完整脚本**：可以编辑整份文本，包含注释、数据源和 pipeline。
- **环节代码**：导入场景可用，只读显示所选节点的实际片段。
- **编排逻辑**：只读展示解析出的片段，便于讲解。
- **检查脚本**：导入场景会重新解析并计算，不仅比较模板内容；语法或数据错误给出位置。
- **运行参数**：输入 JSON 对象，同名值覆盖注释 parameters，其他默认值保留；非法 JSON 不覆盖原参数。
- **恢复示例**：对导入场景恢复导入时的完整文本；对内置场景恢复文档示例。
- **导出 / 复制脚本**：始终使用当前场景的完整文本及文件名，不把环节片段当成完整文件。

完整脚本一旦修改，旧图、旧快照和旧业务结果会隐藏，直到“检查脚本”或“运行演示”重新解析。这样修改代码后不会继续看到与新代码不符的数据。

原有内置场景仍使用固定模板模拟；若在其完整脚本上做了修改，可导出后再导入，使用解释器检查和演示，而不是继续按旧模板计算。

## 6. 原有三个内置场景

| 场景 | 对应资料 | 默认预期结果 |
| --- | --- | --- |
| 按城市统计销售额 | [11 E03](11-完整脚本示例.md) | 杭州 3 单 / 370.50 元，未知 1 单 / 100 元 |
| HTTP 订单筛选 | [11 E02](11-完整脚本示例.md) | 最低金额 100 时 O1003、O1001、O1005；可修改最低金额 |
| RPC 用户资料补全 | [11 E04](11-完整脚本示例.md) | 四条订单保留，U999 城市未知，U001 仍查询两次 |

三个场景支持空订单样例。城市统计还可演示用户响应结构错误；RPC 补全可演示 U003 超时降级。导入场景的输入则来自脚本内存 rows 和注释 mocks，不混用内置的“样例条件”选择器。

## 7. 平台背景与知识答疑

讲解背景时先打开“认识 RowFlow”，再看数据源配置、Row、操作符和 Emit。左下角“开启课堂导览”提供四步说明；右上角“讲解模式”放大代码与关键数据，适合投影。

知识库支持全文搜索、分类、原文阅读、文档互跳及 FAQ 展开；快捷键为 Command+K / Ctrl+K。知识材料包含语法、用户手册和导入协议，文档修改后应同步生成 HTML。

界面不调用真实 AI。生成脚本与知识答疑仍在实际 AI 工具中进行，使用 [12](12-AI生成脚本与答疑演示.md) 或 [16](16-新场景-库存补货演示与AI提示词.md) 的提示词。运行记录仅保存当前页面会话，时间按 Asia/Shanghai 展示，刷新后清空。

## 8. 本轮验收项

基线来自用户要求的“脚本导入、新场景提示词、逐环节可视化、代码展示和运行演示”，以及已有规范。

| ID | 验收行为 |
| --- | --- |
| UI-01 | 单个 HTML 离线打开，无真实 HTTP/RPC/AI 请求，明确本地演示边界 |
| UI-02 | 平台背景、数据源、Row 与图可访问，符合 1.0 文档 |
| UI-03 | 原有三个场景的结果、金额、排序与调用数保持正确 |
| UI-04 | 原有空输入、结构错误、lookup 降级及恢复保持可用 |
| UI-05 | 完整文本编辑、恢复、复制和导出，片段不会误导出 |
| UI-06 | 更新后的文档与 FAQ 已内嵌，可搜索和阅读 |
| UI-07 | 桌面/移动布局、讲解模式、弹窗与导航可用 |
| UI-08 | 文件/拖放/粘贴可导入，校验、错误反馈及原场景保留正确 |
| UI-09 | 注释仅提供讲解和样例，图与结果来自实际代码，无注释也能演示 |
| UI-10 | 每个节点可看真实源码、左右输入与输出；依赖顺序、单步和错误阻断正确 |
| UI-11 | 参数、变量名和业务表达式改变后真正重算；旧快照不能冒充新结果 |
| UI-12 | 库存新场景与提示词可用，默认预算 4722.90，阈值 2000 时仅上海仓 |

## 9. 文件维护与检查

HTML 已包含全部样式、脚本和知识，不依赖旁边的源码目录。维护时编辑 lib 中的源代码、Markdown 和 examples 后，运行 `python3 tools/build_demo.py` 同步生成单文件。

核心解释器检查与浏览器检查位于 tests。浏览器检查需要环境中已有 Playwright 和 Chromium，可用 PLAYWRIGHT_MODULE 指定模块；这是维护工具依赖，不是打开 HTML 的要求。
