

一个模型有几百亿参数， 如果问他一个简单问题， 比如 请你告诉我 猫有几个耳朵，他是怎么运作的。
**稠密模型（Dense）推理，全参数跑一遍，没有「只用一部分参数」的机制。**

完整推理流程（以 LLaMA-7B 为例，约 67 亿参数）
用户输入："请你告诉我 猫有几个耳朵"
步骤 1：分词
Token IDs: [4872, 3121, 29871, 13012, 32001, 29879, 9123, 29901]　"请"　"你"　"告诉我"　"猫"　"有"　"几"　"个"　"耳朵"
8 个 Token，每个是一个整数（词表索引）

步骤 2：Embedding 查表（唯一「稀疏」操作）
Input IDs (8,)　→ Embedding Matrix [128000, 4096]　→ Hidden States (8, 4096)
只读取 8 行，其余 127,992 行完全不碰
得到 8 个 4096 维向量（每个 Token 一个向量）

极简类比：
想象一本词典：
- 词典一共 128000 个词条（Embedding 矩阵 128k 行）
- 你的句子只有 8 个词，你**只查这 8 个词的释义**，剩下十几万词条翻都不翻
- 查到的释义（4096 维向量）交给后面 Transformer 去理解语义## 极简类比

Embedding 查表：**仅生成单词独立基础语义向量，不理解上下文、不做推理、不检索事实知识。上下文语义、关联关系、事实知识，由后续 Transformer 多层前向计算完成。**


步骤 3：32 层 Transformer 全密集前向传播（核心算力）
每一层做两件事（全参数参与）：
Layer 1..32 循环：

# Attention：信息混合

Q = Hidden @ W_Q      # (8, 4096) @ (4096, 4096) → (8, 4096)
K = Hidden @ W_K
V = Hidden @ W_V
Attn = softmax (Q @ K^T / √d) @ V   # 8 个 Token 互相看对方
Hidden = Hidden + Attn @ W_O        # 残差连接


> 类比：读句子时，每个词都在扫一眼整句话里别的词，判断谁和谁有关系。
> 原句：**请你告诉我 猫 有几个耳朵**
- “耳朵” 这个词，会重点关注「猫」，知道耳朵是猫的耳朵，不是人的耳朵；
- “有几个” 会关联后面要回答数量；
- “请你告诉我” 识别这是指令，不是陈述句。
数学上：
每个 token 向量生出 Q（查询）、K（键）、V（值）；
拿 Q 去和所有 K 比对相似度，算出注意力权重，再把 V 加权求和。
👉 本质：**上下文信息混合**。
没有 Attention，每个词的向量是孤立的，不知道词与词之间的关系。

# FFN：Feed-Forward Network 前馈神经网络、作用是 知识提取 / 非线性变换（SwiGLU）

Gate = Hidden @ W_Gate    # (8, 4096) @ (4096, 11008) → (8, 11008)
Up   = Hidden @ W_Up      # (8, 4096) @ (4096, 11008)
Down = SwiGLU (Gate, Up) @ W_Down   # (8, 11008) @ (11008, 4096)
Hidden = Hidden + Down    # 残差连接

关键点：
每一层：Attention 4 个权重矩阵 (WQ,WK,WV,WO) + FFN 3 个权重矩阵 = ~2 亿参数参与矩阵乘
32 层累计：约 67 亿参数全部参与计算
没有任何「if 猫 then 用猫参数」的分支 —— 全部是静态矩阵乘法。

Attention 是**词和词之间互相交换信息**；负责**跨 token 的上下文信息交互**
FFN 负责**单 token 内部的知识挖掘**，基于当前上下文，把预训练存储在权重里的事实、抽象特征融合进向量
> 
> 类比：
> 每张卡片，在看完别的卡片（Attention）之后，**独自翻自己脑子里的知识库，补充事实细节**。
> “猫” 这个向量，在 FFN 计算时，从网络权重里唤醒学到的知识：猫是动物、有头、耳朵数量 2、有尾巴……
> 知识是分布式存在权重矩阵里，矩阵乘加运算就是 “检索 + 组合知识” 的过程。
> 
> 重点区分：
> - Attention：**跨 token 通信（词 ↔ 词）**
> - FFN：**单 token 内部知识提取（单张卡片内部加工）**

### 一层 Transformer Block = 先互相交流（Attention）→ 再单独脑补知识（FFN）
做完一轮，得到更新后的 8 个向量。
**然后送到下一层，再来一轮：互相看 + 单独脑补**。
一共循环 32 次（32 层）。
32 层是什么概念？类比：反复精读、深度思考
- 第 1~ 几层（浅层）：识别语法、词性、谁是主语（猫）、句子结构；
- 中间层：识别语义，理解提问意图：用户在问猫耳朵的数量；
- 深层（后面几层）：激活事实知识，锁定答案是 “2”；
> 每一层都是在上一层加工完的向量基础上，做一轮更深度的提炼。


> 补充：自回归生成后续 token 时会启用 KV Cache，缓存 K/V 的中间激活向量，**但权重矩阵依然全部参与运算，不会减少参数参与**。

步骤 4：输出头
Hidden (最后一层，最后一个 Token 位置) → [4096]
→ Output Head @ W_Out [4096, 128000] → Logits (128000,) # 每个词的未归一化得分，也就是 \(logits = f_\theta(\boldsymbol{X})\)

步骤 5：采样
Softmax (Logits) → 概率分布，用 Top-k / Temperature 采样 → 下一个 Token ID
例如：29901 ("两") → 3121 ("个") → 29934 ("耳") → 29901 ("朵") → EOS 终止符
循环：把新 token 追加回输入序列，再次送入\(f_\theta\)，反复执行步骤 3~5，直到 EOS。

## 为什么简单问题也要跑全参数？

1. **知识分布式存储**：「猫有两只耳朵」不是存放在某几个神经元，而是分布在全网络数亿参数共同形成的权重模式里。
2. **共享能力基座**：即使问题简单，模型仍要解析句法、语义、意图；语言理解、指代、推理共用同一套参数。
3. **架构限制**：稠密 Transformer 是静态计算图，输入形状确定后计算路径固定，没有原生动态路由分支。

## 类比（仅类比，不等同于人脑）

问「1+1=?」大脑皮层大量神经元协同激活，不是单独启用一小块算术区；
问「猫几只耳朵」，语言区、语义记忆、工作记忆协同工作。

- 参数 = 突触连接强度（固定不变）
- 激活值 = 神经元放电模式（随输入动态变化）
