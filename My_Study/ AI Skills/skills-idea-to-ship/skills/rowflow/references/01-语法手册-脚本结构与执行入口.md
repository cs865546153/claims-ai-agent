# 语法手册：脚本结构与执行入口

适用版本：RowFlow 演示规范 1.0。本文定义脚本入口；其余接口见 [文档导航](README.md)。

RowFlow 是本资料构造的演示框架。脚本保留 Groovy 的 Map、List、闭包和表达式写法，由平台注入数据源与流处理 API。文件扩展名为 `.groovy`。本文中的“关键字”指 DSL 方法，不是新增的 Groovy 保留字。

## 1. 完整的最小脚本

建议文件名：`paid_orders.groovy`。

```groovy
pipeline(name: 'paid_orders', dslVersion: '1.0') {
    source('orders', [
        type: 'memory',
        rows: [
            [orderId: 'O1001', status: 'PAID', amount: 120.50G],
            [orderId: 'O1002', status: 'CREATED', amount: 80.00G]
        ]
    ])

    def result = from('orders')
        .filter { r -> r['status'] == 'PAID' }
        .select('orderId', 'amount')

    emit(result)
}
```

预期业务结果：

```json
[
  {"orderId": "O1001", "amount": 120.50}
]
```

## 2. 结构与作用域

一个文件包含一个 `pipeline`，顺序为：声明数据源 → 构造处理链 → `emit`。数据源必须先声明再引用。

| 接口 | 返回值 | 规则 |
| --- | --- | --- |
| `pipeline(Map config, Closure body)` | 无业务返回值 | 定义单个任务及其执行计划 |
| `source(String name, Map config)` | 无 | 注册配置，声明时不发起远程请求 |
| `from(String sourceName)` | `RowStream` | 创建一个独立的惰性读取链；仅接受 `scan` 数据源 |
| `emit(RowStream stream)` | 无 | 唯一终结操作；指定任务输出 |
| `param(String name)` | 参数值 | 必填参数，不存在或为 `null` 时失败 |
| `param(String name, Object defaultValue)` | 参数值或默认值 | 不存在或为 `null` 时使用默认值；保留 `0`、`false`、空字符串 |
| `decimal(Object value)` | `BigDecimal` | 显式数值转换，详见 [Row 与表达式](03-语法手册-Row与表达式.md) |
| `row(Map fields)` | `Row` | 构造只读行对象 |

`source`、`from`、`emit` 只在 `pipeline` 主体内调用。操作符闭包中可以使用 `param`、`decimal`、`row` 以及已经定义的局部变量；不允许在闭包中再声明数据源、构造流或调用 `emit`。

闭包显式声明参数，例如 `{ r -> ... }`、`{ left, right -> ... }`。闭包最后一个表达式是返回值，也可以显式 `return`。示例统一使用带括号的方法调用，操作符的闭包可以放在括号外。

## 3. 任务配置

```groovy
pipeline(
    name: 'city_sales',
    dslVersion: '1.0',
    timeoutMs: 10000,
    maxRows: 10000,
    maxOutputRows: 1000,
    maxLookupCalls: 1000
) {
    // source(...)、处理链、emit(...)
}
```

上面是结构片段。`name` 和 `dslVersion` 必填，其余可省略。`name` 使用 `[a-z][a-z0-9_]{0,63}`；`dslVersion` 必须为字符串 `'1.0'`。配置只接受文档列出的键，未知键直接报错。限制值的范围与触发行为统一见 [执行限制](06-语法手册-执行限制与错误处理.md)。

## 4. 运行参数

平台提交参数是一个 JSON 对象。脚本通过 `param` 读取，无需自行读取环境变量。

提交参数：

```json
{"tenantId": "T001", "minAmount": "100.00", "enabled": false}
```

读取片段：

```groovy
def tenantId = param('tenantId')
def minAmount = decimal(param('minAmount', '0'))
def enabled = param('enabled', true)
```

参数不会自动按字段名推断类型。`minAmount` 在上例中原本是字符串，转换后才用于金额比较。`enabled` 保留实际传入的 `false`。

## 5. 构建与执行

1. 平台解析 Groovy 子集，校验 DSL 版本、配置和 API 白名单。
2. 执行声明阶段，生成计划并检查参数、数据源引用及流的消费关系。
3. 主体结束后，平台执行 `emit` 指向的处理链。
4. 处理链成功后一次性提交业务结果；任一未降级错误使任务失败。

`emit` 在声明阶段注册输出，在执行阶段触发读取。未连接到 `emit` 的链不会读取数据。每个脚本必须恰好调用一次 `emit`。

每个流节点只能有一个下游消费者，不能把同一个变量同时接到两条分支。需要两次独立读取时，可以分别调用 `from('orders')`，但这会产生两次读取，远程结果也可能不同。1.0 不提供缓存或广播分支 API。

## 6. 与 Java Stream 的对应关系

| 需求 | RowFlow 1.0 | Java Stream 中的相近概念 |
| --- | --- | --- |
| 获取输入 | `from('orders')` | `collection.stream()` |
| 筛选与转换 | `filter`、`map`、`flatMap` | 同名中间操作 |
| 投影字段 | `select` | 通常使用 `map` 实现 |
| 排序、截取、去重 | `sorted`、`skip`、`limit`、`distinct` | 相近的中间操作 |
| 组合远程数据 | `join`、`lookup`、`union` | 需要自行组合或扩展 |
| 统计 | `groupBy(...).aggregate(...)` | `collect` 配合收集器 |
| 输出 | `emit(result)` | 终结操作的角色 |

RowFlow 是独立的 DSL，不是 `java.util.stream.Stream` 的包装别名。1.0 的流接口不包含 `collect`、`toList`、`forEach`、`parallel`、`reduce`、`peek`、`findFirst`；也不提供 SQL 字符串执行入口。

## 7. Groovy 子集边界

允许局部 `def`、Map/List 字面量、注释、条件表达式，以及在操作符闭包中使用 `if/else`、`return`。常用值方法限于本手册列出的读取、转换与字符串方法。

脚本不开放任意 `import`、类定义、反射、线程、文件、进程、直接网络请求、动态依赖加载及自行创建 HTTP/RPC 客户端。远程访问统一通过已注册数据源。失败处理使用框架配置，不使用脚本 `try/catch` 吞掉执行错误。

这些限制是 RowFlow 演示规范的约定。实际实现需要 AST 校验与运行隔离，不能仅靠 Groovy 闭包委托实现安全边界。

## 8. 导入、节点讲解与浏览器演示

平台界面支持导入 UTF-8 `.groovy` 文件或粘贴完整脚本。可选的 `// @step id 标题` 与 `/* @rowflow-demo ... */` 都是普通 Groovy 注释，用于给节点命名和提供本地远程响应，不改变 DSL 方法或计算结果。

图与环节源码根据实际脚本解析，数据快照由脚本计算。浏览器实现的是受限 DSL 解释器，不是完整 Groovy 宿主；精确支持范围、输入上限及物化快照与惰性执行的差异见 [导入与可视化约定](15-脚本导入与可视化约定.md)。操作说明见 [平台用户手册](14-平台界面讲解指南.md)。

## 9. 语言设计参考

Map/List、字符串及数字字面量参考 [Groovy Syntax](https://groovy-lang.org/syntax.html)，闭包写法参考 [Groovy Closures](https://groovy-lang.org/closures.html)。中间操作、终结操作和惰性处理的设计参考 [Java Stream 官方 API](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/stream/Stream.html)。RowFlow 自定义 API、限制和错误码以本套资料为准。
