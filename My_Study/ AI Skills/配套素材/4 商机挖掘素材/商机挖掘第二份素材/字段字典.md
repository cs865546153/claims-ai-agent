# 字段字典

所有记录均为合成教学数据；字段原值保留，清洗结果另行输出。CSV 使用 UTF-8 BOM 和 RFC 4180 引号规则；Excel 与 CSV 二选一读取，不能累加。

日期按 Asia/Shanghai 的自然日解释。空单元格表示未知或不适用；不能自行补0。产品代码、客户ID、标的ID均区分大小写。


## 客户表

| 字段 | 类型 | 口径 |
| --- | --- | --- |
| 客户ID | 文本 | 主键；C101—C132 |
| 客户名称 | 文本 | 合成全称，不按名称模糊合并主体 |
| 曾用名或简称 | 文本 | 多个值以中文分号分隔；简称可能重名 |
| 主体类型 | 枚举 | 企业／个体工商户／自然人 |
| 地区 | 文本 | 合成业务区域 |
| 行业 | 文本 | 经营背景，不单凭行业推销 |
| 经营状态 | 枚举 | 正常经营 |
| 员工人数 | 整数或空 | 档案快照；空白表示未知，不等于0 |
| 经营场所数 | 整数 | 档案快照，新增计划见客户动态 |
| 主要标的ID | 文本 | 标的稳定编号，新增场所使用新的编号 |
| 联系人代号 | 文本 | 占位代号，不含真实联系方式 |
| 偏好渠道 | 文本 | 只作为任务草稿字段，不具备发送能力 |
| 营销联系偏好 | 枚举 | 允许／拒绝／待确认；允许不构成自动发送授权 |
| 客户经理ID | 文本 | 责任人占位编号 |
| 档案更新日 | 日期 | YYYY-MM-DD |

## 保单表

| 字段 | 类型 | 口径 |
| --- | --- | --- |
| 记录ID | 文本 | 源记录主键；用于定位重复导出行 |
| 保单ID | 文本 | 业务主键；同一保单可能重复导出，先去重 |
| 客户ID | 文本 | 关联客户表 |
| 产品代码 | 文本 | 关联产品目录 |
| 标的ID | 文本 | 场所或用工群体ID，不能只按产品判断覆盖 |
| 保障对象说明 | 文本 | 教学假设下的保障对象描述 |
| 起保日 | 日期 | 含当日；与终保日均按自然日计算 |
| 终保日 | 日期 | 含当日；续保窗口按终保日减基准日计算 |
| 记录状态 | 枚举 | 有效／待生效／已到期／已退保 |
| 承保来源 | 枚举 | 本方演示／外部演示；均为合成记录 |
| 投保员工数 | 整数或空 | 只用于EMP；空白为不适用或未知，须结合产品判断 |
| 替代原保单ID | 文本或空 | 同主体、产品、标的的明确接续关系 |
| 来源凭据 | 文本 | 合成来源编号；用于追溯，不是实际系统接口 |
| 更新日 | 日期 | 同保单重复时优先较新记录；冲突则人工核对 |

## 客户动态表

| 字段 | 类型 | 口径 |
| --- | --- | --- |
| 动态ID | 文本 | 源记录主键，也是动态原文的锚点 |
| 客户ID | 文本或空 | 空白时仅允许按唯一全称或唯一别名补齐 |
| 客户名原文 | 文本 | 保留空格与简称等源内容 |
| 来源类型 | 文本 | 合成来源类别；不是实际采集接口 |
| 来源定位 | 文本 | 客户动态原文.md中的锚点 |
| 记录日期 | 日期 | 消息发布或访谈记录日期，不是未来计划实施日 |
| 业务发生日 | 日期或空 | 已发生事实的实际日期或未来计划日期，依据原文区分；日期在未来不等于已发生 |
| 入库日期 | 日期 | 决定截至基准日是否可见 |
| 核实状态 | 枚举 | 已核实／未核实／已撤回；撤回记录覆盖被关联原消息 |
| 业务事件ID | 文本 | 同一事件跨来源去重的辅助编号 |
| 标的ID | 文本或空 | 事件涉及的场所或用工群体 |
| 关联动态ID | 文本或空 | 撤回或补充消息指向的原动态 |
| 原文 | 长文本 | 提取信号的原始材料；不含预先标注的商机类型 |

## 跟进记录表

| 字段 | 类型 | 口径 |
| --- | --- | --- |
| 跟进ID | 文本 | 主键 |
| 客户ID | 文本 | 关联客户表 |
| 记录日期 | 日期 | 截至基准日可见 |
| 客户经理ID | 文本 | 责任人占位编号 |
| 产品代码 | 文本或空 | 空表示客户级事项 |
| 标的ID | 文本或空 | 与商机去重时必须核对标的 |
| 关联保单ID | 文本或空 | 已存在任务与续保保单关联 |
| 跟进类型 | 枚举 | 营销／服务 |
| 处理状态 | 枚举 | 已完成／进行中／已关闭 |
| 已有任务ID | 文本或空 | 进行中的同一事项更新原任务，不重复创建 |
| 最早再联系日 | 日期或空 | 业务约定；任务可先生成草稿，触达时间不得提前 |
| 客户表达 | 长文本 | 按原话理解范围；不能把某个产品拒绝扩为所有产品 |
| 下一步约定 | 长文本 | 历史记录，不等于已执行动作 |

## 产品目录

| 字段 | 类型 | 口径 |
| --- | --- | --- |
| 产品代码 | 文本 | 课堂虚构代码，不对应真实在售产品 |
| 教学产品名称 | 文本 | 风险议题标签，不是条款或保障承诺 |
| 允许主体 | 文本 | 仅为本实验的匹配约束 |
| 用途说明 | 文本 | 解释为何值得核实需求 |
| 匹配所需信息 | 文本 | 缺少时转内部核实 |
| 课堂不支持情形 | 文本 | 不能自动认定可承保 |
| 规则版本 | 文本 | DEMO-2026.10-v1 |
