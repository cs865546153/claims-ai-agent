# 完整脚本示例

适用版本：RowFlow 演示规范 1.0。每个 Groovy 代码块是一份独立脚本内容，可按建议文件名保存；各脚本不共用变量。HTTP/RPC 的占位配置及固定响应见 [服务契约](10-示例数据与服务契约.md)。

示例遵循本文档规范，本目录未提供完整 Groovy 宿主。可按 [15](15-脚本导入与可视化约定.md) 的浏览器子集与本地样例导入演示；下面的预期结果用于独立对照，不能证明已通过真实 Groovy 编译或连通远程服务。JSON 数值的小数显示位数不影响金额验收。

## E01：内存订单筛选、金额转换和排序

建议文件名：`memory_paid_orders.groovy`。无必填参数，`minAmount` 默认 `'100.00'`。此例使用简化的三条内存订单，适合最小生成演示。

```groovy
pipeline(name: 'memory_paid_orders', dslVersion: '1.0') {
    source('orders', [
        type: 'memory',
        rows: [
            [orderId: 'O1001', status: 'PAID', amount: '120.50'],
            [orderId: 'O1002', status: 'CREATED', amount: '80.00'],
            [orderId: 'O1003', status: 'PAID', amount: '200.00']
        ]
    ])

    def minAmount = decimal(param('minAmount', '100.00'))

    def result = from('orders')
        .filter { r -> r['status'] == 'PAID' && r['amount'] != null }
        .withFields { r -> [amount: decimal(r['amount'])] }
        .filter { r -> r['amount'] >= minAmount }
        .sorted([direction: 'desc']) { r -> r['amount'] }
        .select('orderId', 'amount')

    emit(result)
}
```

默认参数下的预期结果：

```json
[
  {"orderId":"O1003","amount":200.00},
  {"orderId":"O1001","amount":120.50}
]
```

检查点：输出仅含两个指定字段；金额已经是数值；同一脚本用 `{"minAmount":"150"}` 时仅返回 O1003。

## E02：HTTP 订单筛选与投影

建议文件名：`http_paid_orders.groovy`。参数默认 `tenantId='T001'`、`minAmount='100.00'`。依赖服务契约的订单 HTTP 接口。

```groovy
pipeline(name: 'http_paid_orders', dslVersion: '1.0') {
    source('orders', [
        type: 'http',
        mode: 'scan',
        method: 'GET',
        url: 'https://demo.rowflow.example/api/orders',
        query: [tenantId: param('tenantId', 'T001')],
        credentialRef: 'demo-order-reader',
        rowsPath: 'data.items',
        timeoutMs: 1200,
        retries: 1
    ])

    def minAmount = decimal(param('minAmount', '100.00'))

    def result = from('orders')
        .filter { r -> r['status'] == 'PAID' && r['amount'] != null }
        .withFields { r -> [amount: decimal(r['amount'])] }
        .filter { r -> r['amount'] >= minAmount }
        .sorted([direction: 'desc']) { r -> r['amount'] }
        .select('orderId', 'userId', 'amount')

    emit(result)
}
```

预期结果：

```json
[
  {"orderId":"O1003","userId":"U001","amount":200.00},
  {"orderId":"O1001","userId":"U001","amount":120.50},
  {"orderId":"O1005","userId":"U999","amount":100.00}
]
```

检查点：amount 在转换后比较；金额等于 100 的订单保留；HTTP 请求没有添加契约未定义的 status/minAmount 参数。无重试时远程请求为 1 次。

## E03：HTTP + RPC 左关联，再按城市聚合

建议文件名：`city_sales.groovy`。保留所有 PAID 订单，没有用户资料时归入“未知”；任一扫描源失败则任务失败。

```groovy
pipeline(name: 'city_sales', dslVersion: '1.0') {
    def tenantId = param('tenantId', 'T001')

    source('orders', [
        type: 'http',
        method: 'GET',
        url: 'https://demo.rowflow.example/api/orders',
        query: [tenantId: tenantId],
        credentialRef: 'demo-order-reader',
        rowsPath: 'data.items',
        timeoutMs: 1200,
        retries: 1
    ])

    source('users', [
        type: 'rpc',
        registryRef: 'demo-rpc',
        service: 'demo.user.UserService',
        method: 'listUsers',
        serviceVersion: '1.0',
        args: [tenantId: tenantId],
        rowsPath: 'data.users',
        timeoutMs: 800,
        retries: 1,
        idempotent: true
    ])

    def result = from('orders')
        .filter { r -> r['status'] == 'PAID' }
        .join(from('users'), [
            type: 'left',
            leftKey: { l -> l['userId'] },
            rightKey: { r -> r['userId'] }
        ]) { order, user ->
            [
                orderId: order['orderId'],
                city: user == null ? '未知' : user['city'],
                amount: decimal(order['amount'])
            ]
        }
        .groupBy([city: { r -> r['city'] }])
        .aggregate([
            orderCount: count(),
            totalAmount: sum { r -> r['amount'] },
            averageAmount: avg { r -> r['amount'] }
        ])
        .sorted([direction: 'desc']) { r -> r['totalAmount'] }

    emit(result)
}
```

预期结果：

```json
[
  {"city":"杭州","orderCount":3,"totalAmount":370.50,"averageAmount":123.50},
  {"city":"未知","orderCount":1,"totalAmount":100.00,"averageAmount":100.00}
]
```

检查点：总计 4 个订单、470.50 元；U001 的两张订单都保留。无重试时共 2 次远程请求，执行上先完整读取 join 右侧 users，再消费左侧 orders。

## E04：RPC lookup 补充用户资料，显式允许远程错误降级

建议文件名：`order_user_lookup.groovy`。使用四条内存 PAID 订单和 RPC getUser。此需求明确允许最终源超时或调用失败降级；响应结构、平台权限和任务限制错误仍须失败。

```groovy
pipeline(
    name: 'order_user_lookup',
    dslVersion: '1.0',
    timeoutMs: 10000,
    maxLookupCalls: 20
) {
    source('orders', [
        type: 'memory',
        rows: [
            [orderId: 'O1001', userId: 'U001', status: 'PAID'],
            [orderId: 'O1003', userId: 'U001', status: 'PAID'],
            [orderId: 'O1004', userId: 'U003', status: 'PAID'],
            [orderId: 'O1005', userId: 'U999', status: 'PAID']
        ]
    ])

    source('userById', [
        type: 'rpc',
        mode: 'lookup',
        registryRef: 'demo-rpc',
        service: 'demo.user.UserService',
        method: 'getUser',
        serviceVersion: '1.0',
        args: [tenantId: param('tenantId', 'T001')],
        recordPath: 'data',
        timeoutMs: 800,
        retries: 0
    ])

    def result = from('orders')
        .lookup('userById', [
            request: { r -> [userId: r['userId']] },
            mode: 'left',
            onError: 'null'
        ]) { order, user ->
            [
                orderId: order['orderId'],
                userId: order['userId'],
                city: user == null ? '未知' : user['city']
            ]
        }

    emit(result)
}
```

服务均正常时的预期结果：

```json
[
  {"orderId":"O1001","userId":"U001","city":"杭州"},
  {"orderId":"O1003","userId":"U001","city":"杭州"},
  {"orderId":"O1004","userId":"U003","city":"杭州"},
  {"orderId":"O1005","userId":"U999","city":"未知"}
]
```

检查点：`sourceRequests=4`，`lookupMissRows=1`，`lookupErrorFallbackRows=0`。U001 查询两次，不复用结果。若仅 U003 调用超时，则 O1004 也为未知，正常未命中仍为 1 行，错误降级为 1 行。

## E05：合并渠道、展开商品并统计数量

建议文件名：`sku_quantities.groovy`。本例自带独立的商品明细数据；不使用订单服务的 amount 字段。用于演示 union 与 flatMap。

```groovy
pipeline(name: 'sku_quantities', dslVersion: '1.0') {
    source('webOrders', [
        type: 'memory',
        rows: [
            [orderId: 'O1001', items: [[sku: 'A', qty: 2], [sku: 'B', qty: 1]]],
            [orderId: 'O1002', items: []]
        ]
    ])

    source('storeOrders', [
        type: 'memory',
        rows: [
            [orderId: 'O2001', items: [[sku: 'A', qty: 1]]]
        ]
    ])

    def result = from('webOrders')
        .union(from('storeOrders'))
        .flatMap { r ->
            def items = r['items'] == null ? [] : r['items']
            items.collect { item ->
                [orderId: r['orderId'], sku: item['sku'], qty: item['qty']]
            }
        }
        .groupBy([sku: { r -> r['sku'] }])
        .aggregate([
            itemLineCount: count(),
            totalQty: sum { r -> r['qty'] }
        ])
        .sorted { r -> r['sku'] }

    emit(result)
}
```

预期结果：

```json
[
  {"sku":"A","itemLineCount":2,"totalQty":3},
  {"sku":"B","itemLineCount":1,"totalQty":1}
]
```

检查点：空 items 不产生商品行；count 统计商品明细行，sum 统计数量，二者含义不同；union 本身不去重。

## E06：空输入的全局统计

建议文件名：`empty_summary.groovy`。用于验收全局聚合的空输入规则。

```groovy
pipeline(name: 'empty_summary', dslVersion: '1.0') {
    source('orders', [type: 'memory', rows: []])

    def result = from('orders').aggregate([
        orderCount: count(),
        totalAmount: sum { r -> decimal(r['amount']) },
        averageAmount: avg { r -> decimal(r['amount']) }
    ])

    emit(result)
}
```

预期结果：

```json
[
  {"orderCount":0,"totalAmount":0,"averageAmount":null}
]
```

检查点：空输入不执行指标值闭包，所以不会调用 `decimal(null)`。若改成先 groupBy 再 aggregate，结果应为 `[]`。
