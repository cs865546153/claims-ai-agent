## 2. 符号主义 vs 连接主义
类别	符号主义	连接主义（深度学习 / 大模型）
核心	规则、逻辑、符号推理	神经网络、统计概率、海量数据拟合
知识	人工录入知识库	海量数据隐式学习
优点	推理可解释、可控	泛化强，自然语言理解优秀
缺点	复杂场景规则爆炸	幻觉，黑盒，不可控

> 现代 Agent 常用混合方案：大模型做理解规划 + 符号工具 / 数据库精准执行

## 3. Transformer 结构说明（GPT Decoder-only 架构）

流程顺序：
Token 输入 + 位置编码 → 多头自注意力 Multi-Head Attention → 层归一化 & 残差连接 → 前馈神经网络 FFN → 层归一化 & 残差连接 → 输出层，预测下一个 Token

> 
> 关键点：GPT 是 Decoder-only 自回归模型，逐个生成文本。
> Self-Attention：可以同时看到上下文全部 token，解决 RNN 长文本丢失问题。


## 4. AI Agent 最小核心架构
流程：
用户任务 → 规划器（CoT / ReAct 任务拆解）
规划器判断分支：

1. 不需要工具：直接送入大模型大脑，输出答案给用户
2. 需要工具：调用工具模块（搜索 / 数据库 / API / 代码）→ 获取结果观察 → 回到规划器继续处理

底层支撑模块：
- 记忆模块：短期对话记忆 + 长期持久记忆
- 反思校验模块
记忆模块、反思校验模块均作用于规划器。
> 
> 核心结论：单纯调用 LLM API ≠ Agent。Agent 拥有**闭环执行 + 规划 + 工具 + 记忆**。


## 5. 多 Agent 协作架构（4 种经典模式）
1. **流水线模式**
Agent A → Agent B → Agent C，任务串行接力，上一个输出作为下一个输入。适合顺序处理类任务。
2. **黑板模式**
存在一块共享黑板公共存储。Agent1、Agent2、Agent3 都可以读写这块公共存储，所有智能体共享状态，适合多方协同求解复杂问题。
3. **星型主从模式【工程最常用】**
主 Agent 负责调度规划；主 Agent 下发任务给子 Agent1、子 Agent2、子 Agent3；各个子 Agent 执行完成后把结果返回给主 Agent。
4. **对等网络模式**
Agent1、Agent2、Agent3 互相双向通信，没有中心调度节点，所有 Agent 地位平等，互相协商。
> 
> ⚠️ 区分：上面是**业务协作架构拓扑**；A2A 是**Agent 之间通信协议**，不是架构。


## 6. A2A / MCP / JSON-RPC 关系说明

体系划分：
1. Agent 体系：Agent A、Agent B
2. 模型与外部工具：大模型、外部工具 / 数据库 / 服务

通信关系：
- Agent A <--> Agent B：使用 A2A 协议（Agent 之间通信）
- 大模型 <--> 外部工具：使用 MCP 协议
- A2A、MCP 底层传输可以选用 JSON-RPC

定义：
- A2A：Agent ↔ Agent 智能体之间通信标准
- MCP：大模型 ↔ 外部工具 / 系统
- JSON-RPC：轻量远程调用协议，可作为 A2A/MCP 底层通信载体


## 7. Agent 开发框架选型

判断逻辑：
- 如果开发场景：只做代码开发 Agent → OpenCode，垂直编码 Agent，本地优先
- 如果开发场景：通用业务 Agent、多步骤工作流 → LangGraph，状态机编排，企业主流
- 如果开发场景：知识库问答、私有文档 → LlamaIndex，侧重 RAG 检索增强
- 如果开发场景：基础工具库 → LangChain，基础组件，常搭配 LangGraph
> 
> 通用 Agent 完整技术栈：大模型 API + LangGraph 编排 + 记忆存储 + 工具集

## 8. ReAct Agent 执行循环流程

任务开始 → Thought 模型推理思考 → Action 执行工具调用 → Observation 拿到工具返回结果
判断：任务是否完成？
- 未完成：回到 Thought 继续循环
- 已完成：输出最终结果

ReAct：Agent 最经典的推理 - 行动循环范式。


## 9. Token 计费与成本要点

- 计费规则：**输入 token、输出 token 分开计价，输出通常更贵**
- 单位：百万 token（100w token）
- Agent 场景特点：大量工具返回内容、历史对话，输入 token 占比高，成本容易膨胀
✅ 省钱策略
1. 及时清理无用历史，控制上下文窗口
2. 私有长文档使用 RAG 分片检索，不要全量灌入 prompt
3. 任务分级：简单任务用廉价小模型，复杂推理使用旗舰大模型
